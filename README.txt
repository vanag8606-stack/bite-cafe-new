BITE CAFE — оновлений сайт і Telegram-бот

У комплекті:
- index.html — головна сторінка
- style.css — повністю оновлений дизайн та адаптивна верстка
- script.js — 24 позиції меню, пошук, фільтри, інтерактивний кошик із кількістю та загальною сумою
- bot.py — Telegram-бот імпортує кошик із сайту, одразу показує суму, а потім збирає ім’я, телефон, адресу й спосіб оплати

ВАЖЛИВО ПЕРЕД ПУБЛІКАЦІЄЮ
1. Назви, склад і ціни в меню зараз прикладові. Перевірте та замініть їх на реальне меню Bite Cafe до того, як клієнти почнуть замовляти.
2. Telegram-бот використовує змінні середовища BITE_CAFE_TOKEN і BITE_CAFE_ADMIN_ID. Токен не вписувати у файли й нікому не надсилати.
3. Оскільки токен уже публікувався в чаті, відкличте його в @BotFather і використовуйте новий.
4. У GitHub Pages завантажуйте лише index.html, style.css та script.js у корінь репозиторію. Не видаляйте google4244a3ad37c7d11d.html, якщо він потрібен для Google Search Console.
5. Файл bot.py залишайте на своєму комп'ютері, у папці online-cafe; він не потрібний GitHub Pages.

ЗАПУСК БОТА У WINDOWS POWERSHELL
У VS Code → Terminal → New Terminal введіть по черзі:
$env:BITE_CAFE_TOKEN="ВАШ_НОВИЙ_ТОКЕН"
$env:BITE_CAFE_ADMIN_ID="ВАШ_TELEGRAM_ID"
python bot.py

Спершу відкрийте @BiteCafeOrderBot у Telegram і натисніть /start. Власник також має натиснути /start у боті, щоб бот міг надіслати йому замовлення.

Кошик сайту передається у Telegram через deep-link payload формату cart_<id><qty>... (під лімітом Telegram у 64 символи). Після переходу бот показує страви й суму; кнопка «Далі» запускає збір контактів та адреси. Змінювати ціни потрібно одночасно в script.js і bot.py.
